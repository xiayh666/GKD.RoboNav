# 骨架目标

## G1 - 可统一构建的纯 Rust 库
- 用户故事：在讨论地形算法前，先有独立库及工程构建入口。
- 成功标准：Cargo 可编译 terrain-map；容器 colcon 识别 terrain_map 为 cmake 并与其他工程模块一起构建成功。
- 依赖：已有 Cargo 工作区、ros2 容器中的 Rust 工具链。
- 非目标：本轮不实现地图、特征或通行性算法，不承诺尚未确定的 API。

## G2 - 可验证的体素与并发运行底座
- 用户故事：雷达高吞吐输入可在有界CPU资源下处理，不让异步调度被计算阻塞，并保持地图和人工命令版本一致。
- 成功标准：射线空闲/占用/未知、负坐标和边界、过期/窗口、拒绝事务、历史快照、串并行等价均通过测试；current_thread运行时的背压、确认、关闭和watch语义通过测试；实际容器构建通过；1/2/4工作线程吞吐结果留档。
- 依赖：G1；Tokio及Rayon；Rust ≥1.85。
- 非目标：本阶段不实现地形特征、隧道自动识别、通行性或ROS桥接，不用人工提示冒充自动结论。
