# 2026-11-12 Rust 修正与复验

本轮直接以作者源码定位并修正已有 Rust 实现。官方基线提交仍为
`4b86a469eb5572e70ed575af25b5f15dd06e8e3c`，此前原始对照报告和
results/ 数据保留不覆盖；本轮轨迹与汇总存于 results-corrected/。

## 修正的机制

1. **分开状态和协方差时间。** 原版 Rust 在每个点的时间间隔都加入
   `Q*dt²`，点越密过程噪声越小。现名义状态按采样时刻推进，协方差按
   独立 IMU 时钟推进，对应官方默认 `prop_at_freq_of_imu=true`。
2. **恢复联合观测。** IMU 六轴在同一先验上联合更新，饱和轴 Jacobian
   置零；同采样时间的全部激光点在同一预测状态上线性化并联合更新。
   单点走秩一更新，避免每点多次 30×30 稠密 Joseph 乘法。不再额外插入
   官方流程没有的姿态协方差重置。
3. **恢复地图保点和查询语义。** 同体素保留多个初始返回点，查询中心及
   26 相邻体素的五近邻；写入更新 LRU，按查询时缓存的近邻执行帧末
   `MapIncremental` 占用判定。使用官方形式的列主元 QR 解 `A*n=-1`，
   含秩亏时的基本解及逐邻居距离验证，不再使用 PCA 或单体素单代表点。
4. **恢复初始地图积累。** 首批有效点跨帧累计到可配置阈值（默认 10）后
   建图，避免稀疏首帧的一个点阻止后续同体素点进入地图。比力根据已知
   重力模长初始化，零偏初值置零，后续参与联合估计。

地图容量现在限制体素数，实际点数单独计数。`map_voxels` 与 `map_points`
含义分开。默认查询距离上限 5m，体素枚举仍为 26 邻域。

## 直接官方 C++ 核心数值对照

`filter_oracle.py` 直接包含官方 ESEKF 头文件并提取原始动力学、过程噪声、
Jacobian 和 IMU 观测函数编译，没有重新写一套 C++ 滤波代数。
驱动输入包含点时刻传播、200Hz IMU、饱和轴和同时间两个解析平面约束。

100 次 IMU 中选七个检查点，逐一核对 32 个名义状态标量与完整 30×30 P，
共 6524 个数值；Rust 与 C++ 最大绝对差 `1.3243746377344934e-14`，
测试容差为 `1e-9`。该对照只覆盖滤波核心和小观测批量，不覆盖地图与启动。
fixture、来源和再生成命令在 `src/point_lio/tests/data/`。

另有独立回归证明：把一个 IMU 间隔细分成 1000 个点时刻，P 与单段传播
一致；激光批量 2/29/30/128 行都符合解析 Kalman 后验；相同时间点交换
输入顺序不改变位姿和 P；多点体素、LRU 淘汰与稀疏启动行为均有测试。

## 仍然存在的失败与差异

- **300 体素压力测试仍失败，而且误差增大。** 同一 60s 输入最大位置
  漂移约 1.642475m，超过保留的 0.15m 阈值；默认 100000 体素容量约
  0.026380m。没有删除、忽略该测试或放宽阈值，完整测试命令仍返回失败。
  不能据默认场景通过就宣称完整工程验收完成。
- 原有 floor 生成器把每个坐标重复三次，五近邻可能只有两个不同点。
  这种邻域不能唯一确定平面，QR 基本解与近邻顺序可产生非唯一约束，
  不适合用很小漂移证明退化场景定位可靠。历史 CSV 和结果保留，未删行。
  当前退化回归改用唯一二维地面采样，仍保留原匹配数量、z 误差和
  切向漂移断言；测得 x 漂移约 0.771380m，说明单平面不约束该方向。
- 官方大激光批量（观测数 >=30）分支将 `laser_point_cov` 当信息权重乘，
  小批量分支却将它当方差相加。Rust 明确使用一致的方差模型，状态空间
  解与小批量解一致；解析后验测试覆盖分支边界。这一分支不宣称复刻官方。
- 启动采样组织、空扫描输出、浮点精度和秩亏 QR 基本解选择仍有差异。
  尚未实现可选 24 维 input-state 分支、真实数据精度验证或 Nav2 桥接。
