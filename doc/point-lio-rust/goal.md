# 验收目标

- G1：通过 Cargo 独立构建，无 ROS/PCL/C++ 依赖。
- G2：复现官方 30 维 output-state 的动力学和 IMU/激光观测结构，
  支持饱和轴屏蔽、SO(3) 姿态、外参、零偏和重力误差协方差。
- G3：无先验地图启动，逐点时间融合，实例状态隔离；拒绝无效及倒序输入。
- G4：通过动力学、雅可比、协方差、地图、初始化及合成场景融合测试；
  提供可运行的离线回放和准确的使用说明。
- 真机精度和与官方数据集对比需要后续数据，不用合成测试代替该验收。


## G5 - 独立地图尺度
- 成功标准：索引与插点尺度可分别配置；大筛选格跳过已有点区域，小筛选格允许同索引格增加点；正负坐标均通过回归。
