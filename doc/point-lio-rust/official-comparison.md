# 官方完整程序与 Rust 的同输入对照

这是修正前版本的历史记录。2026-11-12 修正后的实现与复验见
[correction.md](correction.md)，原始轨迹及参数保留不覆盖。

2026-11-11。实际构建并运行作者仓库的完整 ROS 1 `pointlio_mapping` 节点。
官方提交 `4b86a469eb5572e70ed575af25b5f15dd06e8e3c`，分支
`point-lio-with-grid-map`。容器中的 `src/`、`include/` 和 CMakeLists.txt
与官方检出逐文件核对一致，没有替换算法、地图或滤波实现。

## 输入与参数

使用 tools/point_lio_comparison/export_data.py 生成公共 CSV，两侧实际读取
同一份文件。输入 SHA256、版本与环境分别保存在 results/summary.json 和
results/manifest.json；每次官方运行的参数存于 `official_*.params.json`。
Rust 使用 `--ros-f32` 对齐官方 xyz 和逐点时间字段的 float32 精度。
这些结果与 usability.rs 的纯 f64 场景结果会存在细微差别，应以本表比较。

两侧对齐 SI 单位、外参、噪声数值、IMU 量程、平面门限和输入点。
官方 `point_filter_num=1`、关闭空间降采样，以接收同样的全部点；这不是
直接沿用官方示例 launch 的稀疏采样配置。地图保持各自实现：官方 iVox，
Rust 单代表点体素哈希。官方初始化、传播和批量更新流程均保持原样。

官方首帧用于建图，不输出里程计；空点云在其输入回调被丢弃，Rust 会
通过空扫描推进 IMU。因此正常场景官方少一条位姿，恢复场景还少五条。
官方位姿时间为末点采样时刻，Rust 为显式帧末；分别按各自时间计算解析
真值误差，没有把约 1ms 的输出时间差当作姿态误差。

## 实测精度

表中是整个场景的最大误差；姿态为 SO(3) 旋转角误差。

| 场景 | 官方最大位置误差 | Rust 最大位置误差 | 官方最大姿态误差 | Rust 最大姿态误差 |
|---|---:|---:|---:|---:|
| 含噪静止 60s，默认地图容量 | 0.025459m | 0.020259m | 0.009055rad | 0.006286rad |
| 平滑加速旋转 3s，正常量程 | 0.000479m | 0.079637m | 0.010936rad | 0.101525rad |
| 相同旋转，陀螺 z 轴裁剪到 0.3rad/s | 0.000656m | 0.091483m | 0.013476rad | 0.108242rad |
| 单地面 + x 轴加计误差 0.2m/s² | 0.257656m | 0.780142m | 0.000303rad | 0rad |
| 0.5s 空回波 + 加计误差后恢复 | 0.000319m | 0.018642m | 0.000041rad | 0.006532rad |

官方正常/裁剪旋转姿态误差约 0.63°/0.77°，Rust 约 5.82°/6.20°。
静止场景相近，不能说官方所有指标都更好；旋转和恢复场景中当前 Rust
明显落后。单地面两者均有不可观方向漂移，不能用匹配成功数量证明全位姿可靠。
没有将 300 体素压力场景伪装成等容量对照：官方节点没有暴露该容量参数。

## 处理耗时参考

同一台 i5-13500HX 主机，无本任务其他数值测试并行；6 帧输入，首帧建图，
统计后 5 帧。每个点有不同采样时间。两侧使用相同场景及点数。

| 点数/帧 | 官方中位耗时 | Rust 中位耗时 |
|---|---:|---:|
| 1000 | 6.772ms | 26.351ms |
| 10000 | 55.426ms | 258.096ms |
| 20000 | 142.206ms | 509.290ms |

**计时边界并不完全相同，不能据此给出严格加速比。** Rust 测量完整
process_scan（包含检查和排序）；官方使用原始日志中的内部 `t5-t0`，
不包含 ROS 消息接收/解码和预处理。官方日志打印的是累计平均值，
report.py 由它还原单帧时间，再计算中位数；日志和还原值均保留。
官方编译遵从其 CMake（含 `-O3` 与调试符号），Rust 使用 release。

这些样本中，1 万点官方内部处理时间低于 100ms，Rust 完整处理超过
100ms；2 万点两者均超过 100ms。不是长期抖动测量或实车实时保证。

## 结论与可复现记录

本轮证明当前 Rust 实现与官方存在实测行为差距，尤其是旋转轨迹；
仅有小规模合成测试通过不足以宣称等价或可投入实车。没有修改或调参
掩盖差距，也没有据此将问题归因到唯一算法环节。

输入是解析合成平面，不模拟真实扫描可见性、遮挡、动态物体和完整设备
噪声。尚未进行实测数据集评估，不能把本表当作论文结果或真实设备精度。

轨迹、参数、原始官方节点日志、汇总 JSON 见 [results](results/summary.json)。
构建和回放步骤见 [工具说明](../../tools/point_lio_comparison/README.md)。
