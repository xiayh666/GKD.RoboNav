# Point-LIO Rust 重写

依据作者 hku-mars/Point-LIO，提交 4b86a469eb5572e70ed575af25b5f15dd06e8e3c。
停止此前的 C++/ROS 2 移植方向，不采用 PolarBear 源码。

实现不依赖 ROS、PCL、C++ FFI 的 Rust 库。保留官方默认的 30 维
output-state 模型：位置、姿态、雷达到 IMU 旋转和平移、速度、角速度、
比力、重力、陀螺零偏、加计零偏。IMU 作为观测，逐轴拒绝饱和观测，
按每个点的采样时间传播并执行点到平面 EKF 更新。地图从首批观测建立。

输入采用 SI 单位和统一时钟的秒时间戳；调用者负责驱动解码和时间同步。
单个实例顺序调用，无全局状态。静止 IMU 初始化后提交按时间排序的事件；
点云帧接口在更新前检查时间范围，地图在帧末加入，避免同帧自匹配。
输出 IMU 在启动世界系的位姿、速度和完整误差协方差。

2026-11-12 修正后的契约：名义状态按每个采样时间传播，协方差独立按 IMU
时间传播；IMU 六轴和同时间激光点分别联合更新，使用 P-KHP，不再另加
Joseph 稠密乘法/误差重置。地图遵循 DEFAULT iVox 多点节点、26 邻域、
写入 LRU 和 MapIncremental 保点策略；平面使用列主元 QR，跨帧初始累计
到阈值后启用地图。协方差和完整状态用直接编译的官方 C++ 核心生成金标准。

源码大批量噪声权重不一致处采用一致方差解，并用解析后验验证；启动、
数据检查、秩亏基本解及浮点顺序差异不宣称完整等价。当前默认场景回归通过，
300 体素压力测试仍失败；详细证据和边界见 correction.md。

本次范围：核心库、静止初始化、逐点融合、外参配置、在线地图、回放示例、
合成运动验证。不包括 ROS/Nav2 桥接、厂商消息解析、24 维 input-state
分支、回环、先验点云、真实数据精度和实时性能验收。
官方源码原样保留作对照，回滚只需停用 Rust workspace。


### 独立地图尺度
`Config.voxel_size` 仅对应 iVox 索引分辨率；新增 `filter_size_map` 对应 MapIncremental 插点筛选格。两者独立，均须有限且大于零，默认均为 0.3m，保留原默认行为。初始地图仍直接插入，后续筛选仍使用查询阶段缓存的近邻。

### 项目目录收敛
Rust 库统一位于 `src/point_lio`，Cargo 包名仍为 `point-lio`；项目不再携带官方 C++ 仓库。已生成的数值基准和对照结果保留，复现官方算法需使用外部检出的指定提交，基准生成器通过 `--upstream` 显式接受其路径。

### 工程构建入口
普通 CMake 项目 point_lio（LANGUAGES NONE）由 colcon 发现，ALL 目标调用 cargo build --lib --locked，默认 release，构建缓存隔离至 CMake 二进制目录/cargo；不引入 package.xml 或 ament。Cargo 自主管理增量与错误传播。安装仅包含说明和许可证，Rust 消费方仍使用 Cargo path 依赖。
