# MID-360 → Rust Point-LIO 基本位姿

官方驱动CustomMsg/Imu → 薄rclcpp节点 → 独立工作线程串行调用C ABI → 原生Rust PointLio → Odometry与TF。Rust核心不依赖ROS；C ABI只使用固定布局数值数组、指针、长度和状态码，opaque句柄单线程独占，不跨语言传递Rust类型，不允许panic越过ABI。

输入用整数纳秒建立共同相对时间原点，保留逐点时间；加速度g转换m/s²，角速度保持rad/s。IMU覆盖扫描末尾再提交；初始化期间丢弃无法使用的旧扫描，扫描重叠只裁剪已经处理的点。DDS与工作队列有界，过载显式计数。时钟回退/大IMU缺口重置并清空地图，重新静止初始化，诊断记录重置，不保持虚假的跨重置连续性。

输出odom为起始重力对齐局部系、lio_imu为内置IMU；静态lio_imu→livox_frame，外参为p_imu=R*p_lidar+t，默认同向R和t=[-0.011,-0.02329,0.04412]m。该设计外参与MID-360手册IMU位置互逆，并由hku-mars/FAST-LIVO/config/mid360.yaml交叉核对。不是车体base_link，不发布map或机器人安装外参，不加载先验地图。

适配层参数可配置点步长（默认2，保持原始时间）、盲区、地图参数、队列上限、IMU单位及外参。默认步长用于当前约2万点/帧硬件和既有压力结果，不改变滤波方程。仅发布匹配支持足够的帧；诊断匹配数不等于充分可观测证明。实机验证范围为静止接收、有限位姿、TF与基本漂移，运动精度需带真值验证。
